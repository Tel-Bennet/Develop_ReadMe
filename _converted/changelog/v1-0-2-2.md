> 📘 **Info**
>
> **Version:** 1.0.2.2 · **Published:** May 21, 2026 · **Published by:** Telegent Platform Team

This release adds a dedicated **Download Postman** tab to the documentation navigation, giving users a central place to download the mPaaS Postman collection and follow a step-by-step import guide.

---

## New

  
### Download Postman tab added to navigation

A new **Download Postman** tab now appears in the top navigation alongside Changelog. Clicking it opens a page with:

    - A **Download Postman Collection** button that saves `Telegent-mPaaS-Postman-Collection.json` directly to your machine
    - An overview of what's included — 121 endpoints across 16 folders with Bearer auth pre-configured
    - A step-by-step guide covering import, environment setup, authentication, and making your first call

    The collection is a Postman Collection v2.1 file generated from the live OpenAPI spec and regenerated automatically whenever the spec is updated.

  
### Landing page Explore section updated

The **Explore the API** card group on the landing page now includes a **Postman Collection** card linking to the new tab, replacing the previous standalone download button.
