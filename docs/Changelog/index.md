This changelog is published with each product release and documents all changes to the Telegent mPaaS API. Each entry includes a version number, publication date, and a categorized summary of changes.

> 📘 **Info**
>
> Release notes are published with every product update. For urgent security notices, customers are also notified directly via email.

## How to read this changelog

| Category | Description |
|---|---|
| **New** | Newly added endpoints, features, or capabilities |
| **Enhanced** | Improvements to existing functionality |
| **Fixed** | Corrections to incorrect behavior or documentation |
| **Removed** | Features, fields, or endpoints that have been retired |
| **Breaking** | Changes that may require updates to existing integrations |
